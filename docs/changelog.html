Changelog

Release history for dbug. Each version includes bug fixes, new features, and improvements.

v0.1.3 Latest August 2026

Windows visual installer — no more manual zip extraction.

  • Feat Windows installer via Inno Setup with Start Menu and desktop shortcuts
  • Chore GitHub Actions now builds both .exe installer and .zip for Windows
  • Chore Website Windows section shows installer (recommended) and portable zip options
v0.1.2 August 2026

History-aware endpoint loading — see your most recent request details and response when opening endpoints from collections.

  • Feat Opening an endpoint from a collection now loads the most recent history data (URL, headers, body, params)
  • Feat Response pane shows the last response when opening from history or collection
  • Feat Switching endpoints in the collection sidebar also loads latest history
  • Chore Responsive design improvements for small screens on website
v0.1.1 August 2026

JSON schema preview in the spec browser — see actual request/response parameters in formatted JSON.

  • Feat Request body and response schemas now render as formatted JSON with line numbers and syntax highlighting
  • Feat Schema names (e.g. CreateVMRequest, VMInfo) displayed as headings above JSON preview
  • Fix Improved $ref resolution fallback for schema lookups in component schemas
  • Chore Website changelog page with last 5 releases and navigation link
v0.1.0 August 2026

Syntax highlighting themes, persistent window state, font harmonization, and full text selectability across the app.

  • Feat 6 syntax highlighter themes (Default, GitHub, Monokai, Dracula, OneDark, Solarized) with dark/light variants
  • Feat Syntax theme selector in Settings with live JSON preview
  • Feat Window size, position, and maximized state persist across restarts
  • Feat Minimum window size enforced at 900x600
  • Fix Font floor raised app-wide from 9/10px to 11px for better readability
  • Fix All endpoint data text now selectable (method badges, paths, URLs, params, status codes, schemas)
  • Fix Invisible text on dark backgrounds — replaced colorScheme.outline with onSurfaceVariant
  • Fix RenderFlex overflow in endpoint detail view
  • Fix Method badge width increased for long methods (DELETE)
  • Fix Spec browser endpoint tiles show operationId/summary name alongside path
  • Chore Responsive breakpoint changed from 768px to 900px
v0.0.9 August 2026

Add endpoints to collections, collection picker, and improved website navigation.

  • Feat Add endpoints directly to collections from the request builder
  • Feat Collection picker dropdown when adding endpoints
  • Fix Website download button now scrolls to install section
  • Chore Website installation section with OS tabs and direct download links
v0.0.8 August 2026

Dark/light theme legibility fixes, request name sync, and scrollable response body.

  • Fix Request name now updates automatically when switching endpoints
  • Fix Cursor-following URL tooltip shows resolved URL with variable substitution
  • Fix Response body overflow — now scrollable with proper constraints
  • Fix Request headers legibility in dark theme
  • Fix Theme-aware syntax highlighting in response viewer
v0.0.7 August 2026

Dark theme legibility overhaul with neutral surfaces and readable text colors.

  • Feat cal.com-inspired theme with neutral dark surfaces
  • Feat Redesigned website with cal.com design system
  • Fix Neutral surface colors replacing overly dark backgrounds
  • Fix Readable text colors across all screens
  • Fix Remaining outline text color issues for dark mode contrast
v0.0.3 July 2026

Code quality fixes, deployment setup, and cross-platform improvements.

  • Feat Cross-platform app icons for Linux, macOS, and Windows
  • Feat Linux desktop integration with .desktop entry
  • Feat Install script for downloading, installing, and updating dbug
  • Feat Release CI for automated builds
  • Fix Select dropdowns and environment activation
  • Fix Split ratio persistence
  • Chore Code quality improvements and test coverage
  • Chore GitHub Pages deployment for website
