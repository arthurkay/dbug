Everything you need

All the tools to test, debug, and mock your APIs — completely offline.

Request Builder

Send HTTP requests with full control over headers, query params, body (JSON, form data, raw), and auth (Bearer, Basic, API Key).

Collections

Organize requests into collections with global headers and auth. Import and export as JSON files.

History

Automatic logging of every request with response status, timing, and body. Search and revisit any past request.

OpenAPI Specs

Import OpenAPI 3.x specs from files or URLs. Browse endpoints with full parameter tables, request body schemas, and response structures.

Environments

Define variables per environment and switch between them. Use {{variable}} syntax in URLs, headers, and body.

Mock Server

Built-in mock server on port 3001. Define endpoints with custom status codes, headers, response bodies, and delays.

Collection Auth

Set global auth (Bearer, Basic, API Key) at the collection level. Automatically inherited by all requests.

OS-Native Theme

Fully adapts to your system accent color and dark/light mode. Built with Yaru for a native Linux feel.
